Project 1: Travel Destination Webpage

This project presents information about a travel destination, including its attractions and important features. It uses HTML headings, paragraphs, lists, images and hyperlinks to organize information and help visitors explore the destination.

Project 2: Student Registration Form

This project demonstrates how to create a student registration form using HTML. It includes text inputs, labels, radio buttons, checkboxes and dropdown menus to collect student information. The required attribute helps ensure that compulsory fields are completed before the form can be submitted.

Project 3: College Event Webpage

This project presents information about a college event using HTML5 semantic elements such as header, nav, main, section and footer. It also demonstrates hyperlinks, images and multimedia elements such as audio and video. The webpage organizes event information into meaningful sections.

Project 4: C++ Pattern Practice

This is a programming practice project in which I write C++ programs to print different patterns using loops. It helps me understand nested loops, iteration and the basic structure of C++ programs while improving my logical thinking and problem-solving skills.
